**Nintendo Switch / 電車でGO!! はしろう山手線**

- 대상 버전: 일본판 v1.1.2 (Title ID `0100BC501355A000`)
- 현재 버전: **V1.0.0**

> ⚠️ 비공식 팬 번역 패치입니다.
> 게임 본체는 포함되어 있지 않으며, 정식으로 구매한 게임이 필요합니다. 원작사·유통사와 무관합니다.

텍스트와 이미지 대부분을 한글화했으나, 미비한 부분이 있을 수 있습니다.

## 설치 방법 (Atmosphere / 에뮬레이터)

1. [Releases](https://github.com/hardwater-P/Go_by_Train_Hashiro_Yamanote_Line_Kor_RELEASE/releases)에서 `Go_by_Train_Hashiro_Yamanote_Line_V1.0.zip`을 받습니다.
2. 압축을 풀고 `atmosphere` 폴더를 SD카드 루트에 덮어씁니다. (에뮬레이터는 `romfs` 하위 파일을 mod 폴더에 넣습니다.)
3. 설치되는 경로: `atmosphere/contents/0100BC501355A000/romfs/DgocGame/Content/Paks/`
4. 되돌리려면 `backup` 폴더의 원본 pak으로 복원하거나, 위 폴더에 넣은 pak을 삭제하면 됩니다.

**필요 조건:** 일본판 v1.1.2 (다른 버전에서는 동작을 보장하지 않습니다.)
